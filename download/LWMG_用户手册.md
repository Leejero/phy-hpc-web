# WorkBuddy 记忆治理 · 使用说明

一个用于 **WorkBuddy 项目生命周期治理与记忆维护** 的 Windows 桌面工具。它帮助你发现长期闲置的项目、需要复核的记忆，并导出治理台账；**不是通用文件搜索器或清理工具**。

## 1. 启动与系统要求

- 运行文件：`LWMG.exe`
- 支持 Windows，需系统具备 **WebView2 Runtime**（现代 Windows 通常已安装；若启动失败，请安装 Microsoft Edge WebView2 Runtime 后重试）。
- 双击 exe 即可启动，无需安装 Python、Node.js，也无需手动启动服务或打开浏览器。
- 关闭应用窗口即退出程序。
- 当前版本：**v1.2.0（versionCode 2）**。启动后自动检查 GitHub Pages 上的 `data/lwmg_version.json`；仅发现更高 `versionCode` 时，三个页面的顶栏最右侧显示向上箭头「新版」。点击箭头在系统浏览器打开「自开发应用」下载页。离线或检查失败时不显示提示，不影响本地功能。

## 2. 首次使用：选择工作区

1. 双击应用，进入欢迎界面。
2. 点击“选择文件夹…”，选择 **WorkBuddy 根目录**，例如：

   ```text
   C:\Users\你的用户名\WorkBuddy
   ```

   请选择包含各项目文件夹的根目录，**不要只选择某一个项目**。
3. 核对页面检测到的项目数、记忆文件数等信息。
4. 点击“进入项目治理台”或“进入记忆浏览器”。

工作区路径仅保存在应用所在目录的 `workspace.json`，供下次启动使用。更换电脑或目录后，可通过顶部“更换工作区”重新指定。

## 3. 主要功能

### 项目治理台

- 查看活跃、休眠、长期闲置、空壳等项目状态。
- 查看记忆复核优先级：P0、P1、P2，以及稳定或受托管的记忆。
- 使用选项卡和筛选条件定位项目或记忆。
- 点击“重新盘点”刷新当前统计结果。
- 双击项目或记忆台账中的行：项目行在资源管理器中打开项目根目录；记忆行打开所在目录并选中对应文件。记忆缺口清单中的项目行也支持双击打开。
- 点击“导出台账”，选择保存位置，生成 Markdown 格式的项目与记忆治理报告。

**判定结果只是建议，不代表可以直接删除项目或记忆。**

### 项目活跃如何判定？

- 在活跃窗口（默认 14 天）内，至少有 **2 份有效正文文件**，且修改时间覆盖至少 **2 个不同日期**，才判为活跃。
- 全部有效正文都在活跃窗口内的新项目可例外，避免新项目只有一份 README 时被误判。
- 隐藏工具目录、依赖、构建物、压缩/安装包、备份、日志、缓存和记忆写入均不作为活跃证据。
- 单个新文件或单点正文修改不会让旧项目恢复活跃；这些项目按最新有效正文时间归入休眠或僵尸候选。
- 项目表中的“活跃证据（窗口内）”显示文件数、修改日数与原因；悬停可查看最新证据文件。
- “最近有效正文修改”不等同于打开、浏览或聊天时间，判定结果仍需结合实际用途复核。

### 记忆浏览器

- 浏览三类记忆：用户级长期记忆、全部项目的项目级记忆、用户级 Skills。
- 展开项目目录查看对应的 `.workbuddy` 记忆文件。
- 使用顶部搜索框进行全文检索。
- 点击文件查看 Markdown 内容。

### 更换工作区

在顶部导航点击“更换工作区”，返回欢迎页重新选择 WorkBuddy 根目录。

## 4. 读取范围与安全边界

程序读取：

- `<工作区>/<项目>/.workbuddy/memory/*.md`
- `<工作区>/<项目>/.workbuddy/MEMORY.md`
- `~/.workbuddy/user-*-personal/*.md`
- `~/.workbuddy/skills/**/*.md`

程序不会：

- 自动移动、重命名或删除项目与记忆文件。
- 将普通项目代码、PDF、PPT 等纳入记忆全文检索。
- 扫描所选工作区之外的任意项目位置。
- 上传记忆内容到远程服务。

唯一的业务写入操作是：**在用户明确选择保存位置后，生成一份新的 Markdown 台账**。此外，应用会保存自身的 `workspace.json` 配置。

## 5. 分发与常见问题

### 可以把 exe 发给别人吗？

可以。只需分发 `LWMG.exe` 一个文件，约 **13.43 MB**（13,426,315 字节），不需要附带源码或静态资源。接收方需具备 WebView2 Runtime。

### 为什么第一次没有看到项目？

需要先选择正确的 **WorkBuddy 根目录**，而不是某个单独项目或某个 `.workbuddy/memory` 子目录。

### 为什么用户级记忆与所选目录无关？

用户级记忆和 Skills 从当前 Windows 用户目录下的 `~/.workbuddy/` 自动读取；项目级记忆来自你选择的工作区。

### 可以直接根据台账清理文件吗？

不要直接批量清理。台账只提供复核线索；任何移动或删除操作都应先确认具体文件、备份，并使用系统回收站。应用本身不会执行这些操作。

### 应用无法启动怎么办？

确认 Windows WebView2 Runtime 可用，并尝试将 exe 放到有写入权限的普通文件夹后重新启动。启动失败时应用会显示错误提示。
