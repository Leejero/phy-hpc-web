## 1. 快速上手

三步完成一份图文操作说明：

1. 点击右上角**「开始录制」**按钮（或按热键 F8）；
2. 像平常一样操作电脑——点击、打字、切换窗口都会被自动记录为步骤；
3. 再次点击**「开始录制」**（或再按 F8）结束，填写说明标题，点击**「导出」**选择格式即可。

## 2. 录制

### 2.1 自动捕捉的内容

| 操作 | 记录结果 |
|---|---|
| 鼠标单击 | 一步「点击」，截图上以红色圆圈标出点击位置 |
| 鼠标拖拽 | 一步「拖拽操作」（按下→松开位移超过 6 px 判为拖拽） |
| 双击 | 合并为一步，不产生冗余记录 |
| 键盘输入 | 一步「输入文本」，停止敲键约 1 秒后收步；同窗口相邻输入自动合并 |
| 窗口画面变化 | 一步「页面变化」（如弹窗出现、页面跳转） |

点击标识的样式（大红圈 / 自定义图片）与颜色可在 **设置 → 个性设置** 中修改。

### 2.2 热键

| 热键 | 作用 | 可否修改 |
|---|---|---|
| F8 | 开始 / 停止录制（录制中按下即停止，未录制时按下即开始） | 可改（F8–F12，见设置 → 热键） |
| F9 | 暂停 / 恢复采集（仅录制中生效；敏感操作前按下可临时不记录） | 可改（见设置 → 敏感防护） |

> 采用单功能键是为了避免与正常输入录制冲突。若暂停热键与开始/停止热键相同，暂停热键将不会注册。

### 2.3 截图范围

点击**「设定区域」**后，在屏幕上按住左键拖拽框选区域；**右键或 Esc 取消**。设定后只记录该范围内的点击，状态栏显示当前范围（聚焦 / 全屏）。

### 2.4 敏感信息防护

- **密码输入框**：自动识别并跳过记录，无需任何配置；
- **进程黑名单 / 窗口标题黑名单**：命中黑名单的窗口内，按键与点击一律不记录；
  - 进程：如 `chrome`、`notepad`，可带或不带 `.exe`，按进程名匹配，忽略大小写；
  - 窗口标题：标题**包含**该关键词即命中，忽略大小写；
  - 每行一项，也支持逗号、分号分隔。

## 3. 步骤管理

- **说明标题**：顶部输入框填写文档标题，将显示在导出文档的封面/标题位置；
- **每一步**可展开编辑三要素：标题、说明、备注（备注默认折叠，点「＋ 添加备注」展开；留空时自动收起，不占卡片空间）；
- **搜索框**：按标题 / 说明 / 备注 / 窗口名筛选步骤（空格分词、须全部命中）；
- **撤销**：主界面 Ctrl+Z 可撤销文档级操作；
- **步骤快捷键**：在步骤卡片内点击任意编辑框后，Ctrl+↑ / Ctrl+↓ 移动该步骤，Ctrl+D 删除该步骤（删除需确认、可 Ctrl+Z 撤销；可连按连续移动）；
- **长会话流畅滚动**：步骤超过 120 步时自动只渲染可视区域附近的卡片（滚动到哪显示到哪），千步级会话同样流畅；
- **批删**：勾选多个步骤一次性删除；
- **清空**：删除当前全部步骤；
- **历史**：双击列表项或点「载入」可继续编辑历史会话。

## 4. 截图编辑器

在步骤卡片上点击**「编辑截图」**打开编辑器（打码功能已合并其中）。

### 4.1 工具一览（第一行）

| 工具 | 用法 |
|---|---|
| 选择 | 点击已绘标注选中，按住可拖动位置；按 Delete 键删除选中项 |
| 打码 | 拖拽框选区域，区域内像素模糊化 |
| 裁剪 | 拖拽框选保留区域，点第二行**「应用裁剪」**生效；区域外的标注一并丢弃 |
| 箭头 | 从起点拖拽到终点，箭头指向终点 |
| 矩形 | 拖拽绘制矩形框 |
| 文字 | 点击落点后输入文字 |
| 序号 | 点击落点放置编号圆标（自动递增） |

### 4.2 属性栏（第二行）

- **颜色 / 粗细 / 填充**：作用于箭头、矩形、文字、序号；
- **放大镜**：勾选后鼠标悬停处显示 3× 放大视图，便于精确落点；
- **删除选中**：删除当前选中的标注；
- **应用裁剪**：确认裁剪操作。

### 4.3 右上角操作

- **撤销 / 重做**：回退或恢复标注操作；
- **恢复原图**：丢弃全部标注；
- **取消**：放弃本次编辑；**保存**：应用编辑到步骤。

## 5. 导出

点击主界面**「导出」**后弹窗选择格式（HTML / Word / PDF / Markdown / PPTX）：

| 格式 | 产物形态 |
|---|---|
| HTML 网页 | 单文件，图片直接嵌入；含可点击目录与交互功能（见下） |
| Word 文档 | 单文件，图片直接嵌入；标题后含步骤目录 |
| PDF | 单文件，图片直接嵌入；标题后含步骤目录 |
| Markdown | 一个整包文件夹（含图片目录）；目录带锚点链接 |
| PPTX 演示文稿 | 单文件，封面 + 每步一页（步骤标题 / 说明备注 / 截图），适合汇报演示 |

**HTML 交互功能**：导出的网页中，点击步骤标题行可**折叠 / 展开**该步骤；目录区提供**「全部展开 / 全部折叠」**按钮；页面向下滚动后右下角出现**「返回顶部」**浮动按钮。

**导出位置记忆**：导出对话框会自动定位到上次导出的目录（跨会话生效）；目录已被删除或移动时回落系统默认位置。

**导出文档署名**：每份导出文档（HTML / Word / PDF / Markdown）末尾均附「本文档由 StepSnap 生成 · 开发者：Leejero」及可删除说明；PPTX 的署名在封面副标题（「由 StepSnap 生成 · 开发者：Leejero」）。该段仅为软件署名，可自行删除，不影响文档内容。

**导出图片最大宽度**（设置 → 导出选项）：作用于导出文档中内嵌截图，单位像素，最小 640（默认 2560）；超宽截图自动等比缩小，录制时的原始截图不受影响。

## 6. 设置

| 面板 | 内容 |
|---|---|
| 个性设置 | Logo、主色、字体（微软雅黑 / 宋体 / 黑体 / 楷体 / 仿宋等）、点击标识（大红圈 / 自定义图片）及颜色，附实时预览 |
| 导出选项 | 导出图片最大宽度（见 §5） |
| 热键 | 开始/停止录制热键，F8–F12 单选（见 §2.2） |
| 录制参数 | 见下表 |
| 敏感防护 | 暂停热键、进程黑名单、窗口标题黑名单（见 §2.4） |
| 关于 | 版本信息 |

**录制参数**（留空或填非法值，保存时自动恢复默认）：

| 参数 | 默认 | 单位 | 含义 |
|---|---|---|---|
| 键盘分段空闲 | 1.0 | 秒 | 停止敲键多久后把输入收成一步（越大越少拆步） |
| 输入合并间隔 | 5.0 | 秒 | 停止后同窗口相邻文本合并的判定窗口 |
| 拖拽判定位移 | 6 | px | 按住拖动超过该距离记为「拖拽」而非「点击」 |
| 双击时间窗 | 500 | ms | 判定两次点击为「双击」的时间阈值 |
| 双击位移容差 | 8 | px | 判定「双击」的位移容差 |

## 7. 数据存储位置

默认存储位置（可在设置 → 录制参数 → 数据存储位置中更改）：

| 内容 | 路径 |
|---|---|
| 录制会话（步骤 + 截图） | `C:\Users\<用户名>\AppData\Roaming\OperationManualGenerator\sessions\` |
| 品牌与配置 | `C:\Users\<用户名>\AppData\Roaming\OperationManualGenerator\branding.json` |
| 运行日志 | `C:\Users\<用户名>\AppData\Roaming\OperationManualGenerator\md_patch.log` |

主界面「历史」对话框底部显示保存目录。

**更改存储位置**：设置 → 录制参数 → 「数据存储位置 · 更改…」选择新目录后保存。新录制与截图立即保存到新位置；历史面板同时显示新旧两处会话；旧数据不会自动迁移（如需搬移请手动复制 sessions 文件夹）；目录被删除后自动回落默认位置。日志始终保留在默认位置（便于诊断）。

## 8. 常见问题

**Q1：点击没有被画圈 / 没有记录？**
依次检查：① 是否点在了 StepSnap 自己的窗口上——本程序窗口内的操作按设计不记录；② 是否按了暂停热键（F9）；③ 目标窗口是否命中黑名单。若程序启动录制后弹出**「输入监听未正常运行」**提示框，说明低层输入钩子被安全软件拦截——关闭程序后重新运行并在安全软件中放行即可。排查详情可查看运行日志（§7）。

**Q2：录制中途点了没反应、后续不再记录？**
旧版本存在低层钩子超时被系统摘除的问题，当前版本已修复（点击处理移入后台线程）。若仍出现，请将日志发送给维护者。

**Q3：编辑器里画的箭头变成了矩形？**
当前版本已修复（拖拽预览按工具类型区分）。请确认使用的是最新构建。

**Q4：想给截图上的敏感信息打码？**
打开「编辑截图」，选择**打码**工具框选即可；标注对象均可用**选择**工具移动或按 Delete 删除。

**Q5：导出的 Markdown 是一个文件吗？**
不是，Markdown 导出为一个整包文件夹（文档 + 图片目录），HTML / Word / PDF / PPTX 均为单文件且图片内嵌（PPTX 为封面 + 每步一页）。
