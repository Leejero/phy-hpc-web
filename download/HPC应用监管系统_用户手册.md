# 物电 HPC 集群监控 用户手册

> 版本：v1.0.1（安卓 debug 版）｜ 适用系统：Android 8.0 及以上

---

## 1. 简介

「物电 HPC 集群监控」是面向物理与光电工程学院高性能计算集群的移动端监控工具，基于 WebView 封装，可在安卓手机上随时查看集群运行状态。

- **软件名称**：物电 HPC 集群监控
- **支持平台**：仅安卓（Android 8.0+，依赖系统 WebView）；暂无 iOS 版本
- **数据来源**：集群后台定时采集并推送到 GitHub，App 实时拉取
- **开发者**：Leejero

## 2. 安装

1. 从群里获取安装包 **`物电HPC集群监控.apk`**。
2. 安卓系统默认禁止未知来源应用安装，需先开启权限：
   - 路径：`设置 > 安全（或「应用安装」/「特殊应用权限」） > 允许「未知来源」`，或在安装弹窗中点击「设置 > 允许此来源安装」。
3. 点击安装包按提示完成安装。
4. **升级 / 覆盖安装**：新版本直接安装即可，无需卸载旧版，个人设置（导航、夜间模式、字号）会保留。

### 文件名变成「物电HPC集群监控.apk.1」怎么办

部分手机下载后文件名会变成 `物电HPC集群监控.apk.1`（末尾多了 `.1`）：

- **原因**：「下载」目录里已存在同名文件，系统为防覆盖自动追加序号。
- **影响**：手机不识别 `.apk.1` 扩展名，无法直接安装。
- **解决（任选其一）**：
  1. 把 `物电HPC集群监控.apk.1` 重命名为 `物电HPC集群监控.apk`（删掉 `.1`）再安装；
  2. 删除旧版 `物电HPC集群监控.apk` 后重新下载，即可得到干净的 `.apk`。

该文件与源文件内容一致，重命名后即可正常安装。

## 3. 界面与导航

整体布局自上而下：

- **顶部栏**：标题与「更新时间 / 刷新状态」，数据超过 3 小时未更新时此处变红并提示离线。
- **中部内容区**：当前功能页内容。
- **底部导航栏**：默认 5 项——看板 / 任务 / 节点 / QOS / 更多。
- **右下角悬浮按钮**：圆形刷新键，点击手动刷新。

**导航规则**：「看板」固定最左、「更多」固定最右且二者始终存在；中间最多再放 3 项，超出部分自动省略。

**自定义底部导航**：
1. 进入「更多 > 设置 > 自定义底部导航」；
2. 勾选 / 取消各功能（看板、任务、节点、QOS、用户、在线、INCAR 手册、历史）；
3. 保存后底部导航按所选顺序重新排列（看板、更多位置不变，总数不超过 5）。

## 4. 看板

- **概览卡片**：集群总节点数、总核心数、已用 / 空闲核心、整体负载等，所有数字统一为蓝色，便于一眼读取。
- **分区与 QOS 概览**：各分区节点、核心占用与配额情况。
- **离线提示**：若数据在集群侧被收集的时间距今超过 **3 小时**，看板顶部出现橙色横幅「服务器离线：数据已 X 小时 X 分未更新」，顶部更新栏同时变红。这说明集群采集 / 推送服务可能已停止，需到集群侧排查。

---

## 5. 任务

任务列表按分区组织，每行任务包含两行信息：

- **第一行**：`用户名` +（运行中显示「节点: xxx」/ 等待中显示「原因: xxx」）+ 状态标签（运行中 / 等待中 / 异常等）。
- **第二行**：`任务名 · #作业号 · N CPU · 运行时间`。

**状态筛选**：任务页顶部按钮「全部 / 运行中 / 等待中」可切换过滤。

**元信息说明**：
- **运行中**任务：第一行人名后显示其跑在哪个**节点**（如 `节点: comput02`）。
- **等待中**任务：第一行人名后显示**排队原因**（如 `(QOSGrpCpuLimit)` 表示受 QOS 组 CPU 配额限制）。

任务字体大小随「设置 > 字号」档位变化。

---

## 6. 节点

- 节点以**两列网格**卡片展示，每张卡显示节点名、状态（运行中 / 空闲 / 异常 / 混合 / 已分配）及核心占用进度条（绿 / 橙 / 红表示占用率高低）。
- 顶部筛选条「全部 / 异常 / 空闲 / 运行中 / 已分配」可横向滑动筛选，不换行。

---

## 7. 用户资源 / 在线终端 / 历史 / INCAR 手册

入口均在「更多 > 更多功能」：

- **用户资源**：各用户的作业汇总与资源占用。
- **在线终端**：每行显示「用户名（完整显示）+ tty / 来源 / 空闲时长」，用户名独占一行不会被截断。
- **最近查看**：最近访问过的节点或作业的快捷入口。
- **INCAR 手册**：内置 INCAR 参数说明（WebView 内嵌页面）。**夜间模式下采用反色显示**，个别配图颜色会反转，但不影响文字阅读。

## 8. 更多 / 设置

「更多」页含快捷功能与设置：

- **快捷功能**：异常节点 / 空闲节点 / 运行中任务 / 等待中任务，点击一键跳转对应筛选。
- **设置项**：
  - **夜间模式**：开 / 关，切换深色主题（含 INCAR 手册反色）。
  - **字号**：小 / 中 / 大 三档循环，全局生效。
  - **自定义底部导航**：进入编辑（见第 3 节）。
- **关于**：物电学院 HPC 集群监控；数据由集群 cron 自动采集推送（日间约 20 分钟 / 次，夜间约 2 小时 / 次）；开发者：Leejero。

## 9. 数据更新与离线提示

- **自动刷新**：App 在前台可见时，每 **5 分钟**自动拉取一次最新数据。
- **手动刷新**：点击右下角圆形刷新按钮，或下拉页面触发。
- **多源取最新**：App 依次尝试 `github.io > raw.githubusercontent > jsDelivr > 本地打包快照`，比较各源数据的采集时间，**自动采用最新的一份**，避免被旧缓存卡住。
- **离线判定**：若最新数据距当前已超过 3 小时，判定集群采集服务离线，界面给出醒目提示（见第 4 节）。

## 10. 常见问题（FAQ）

| 问题 | 处理 |
|------|------|
| 文件名变成 `*.apk.1` 无法安装 | 重命名为 `.apk`，或删旧文件重新下载（见第 2 节） |
| 数据长时间不更新 | 先确认网络连通；查看是否提示「服务器离线」；App 已优化为多源取最新，若仍滞后多为集群侧未推送 |
| 在线终端显示为 0 | 受集群采集端 `who -u` 限制（仅本节点会话），属集群侧问题，App 暂无法修正 |
| 配置换手机后丢失 | 导航、夜间模式、字号仅存本机，换机或清缓存后恢复默认，需重新设置 |
| 闪退 / 白屏 | 重启 App；无效则清除 App 缓存；仍异常请反馈机型、安卓版本与截图 |
